# MyPatientHUB

## Project Overview

MyPatientHUB is a healthcare web application built with React. It provides a user-friendly interface for accessing healthcare-related features, managing account information, and exploring healthcare services.

The project aims to make healthcare information and services easier to access through a simple, organized, and responsive web interface.

## Features

- **Dashboard:** Access the main sections of the application.
- **Find Doctor:** Explore doctor-related information.
- **Find Clinic:** Browse clinic information and clinic locations.
- **Find Pharmacy:** Explore pharmacy and medicine information.
- **Marketplace:** Browse marketplace items and services.
- **My Dependents:** Manage dependent information.
- **My Account:** View and manage profile information.
- **Settings:** Access account and application settings.
- **Login:** Access the application's login interface.
- **Responsive Design:** Use the application on different screen sizes.
- **Dark Mode:** Switch between light and dark themes.

## Getting Started

Follow these instructions to run the project on your local computer.

### Prerequisites

Install the following software:

- [Node.js and npm](https://nodejs.org/)
- [Git](https://git-scm.com/)
- [Visual Studio Code](https://code.visualstudio.com/) (recommended)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/M-A-A4/Final-MyPatientHUB.git
```

**2. Open the project folder**

```bash
cd Final-MyPatientHUB
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

The application will reload when you make changes to the source files.

## Available Scripts

### `npm start`

Runs the application in development mode.

### `npm test`

### `npm run build`
